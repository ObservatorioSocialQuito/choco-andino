# Chocó Andino · El territorio y sus datos

Presentación interactiva de los resultados zonales de la EMVIGMU-Q 2025.

- `index.html`: mapa de las seis parroquias y recorrido de 12 temas.
- `presentacion.html`: presentación completa de resultados.
- `OFL.txt`: licencia de la tipografía Montserrat.

Los archivos HTML incluyen sus datos, estilos y recursos; funcionan sin instalación. Los resultados de la encuesta corresponden a toda la Administración Zonal Chocó Andino, no a cada parroquia.

## GitHub Pages

1. Crear un repositorio público, por ejemplo `choco-andino`, en la cuenta de GitHub elegida.
2. Subir el contenido de esta carpeta a la raíz del repositorio, dejando `index.html` directamente en la raíz. No subir el ZIP como un único archivo.
3. Abrir Settings → Pages. En Source, elegir Deploy from a branch; seleccionar `main` y `/(root)`; guardar.
4. Esperar a que GitHub termine el despliegue y abrir la dirección que muestre la sección Pages.

Documentación: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
